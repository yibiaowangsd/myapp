# 1.3.0 时间线首页、应用连接与提效

应用版本：1.3.0（6），2026-10-15。复用原签名、包名、Room V1 数据与密钥；可覆盖安装。

## 页面行为

启动直接进入时间线，日期、分类、照片、活动图标与应用区间共同组织一天。应用片段直接显示开始和结束时间，不用总时长代替时段。顶部“一天总结”保留此前的回顾、四项统计和分时段图文卡片。

底部是“时间线 / 回忆 / 连接 / 我的”。从演示进入连接页时自动退出示例，显示真实权限与应用状态。连接页默认进入“应用连接”，从当前设备可见的已安装应用读取名称和图标，支持搜索。展开某个应用可开关参与记录、选择通知文字解析；缺少通知权限时直接请求系统授权。关闭参与记录将该应用加入排除集合；通知正文依然需要本人逐个选择。

“来源与后台”集中管理系统应用使用、音乐/播客、日历、图库、健康和计步。它展示实际授权和设备支持状态，而不是一律显示连接成功。华为账号健康数据单独标明尚未接入。

## 扩展的应用连接体验

| 应用类型 | 当前真实接入方式 | 不能据此推断的内容 |
|---|---|---|
| 微信、QQ、浏览器、地图及其他已安装应用 | Android UsageEvents 使用区间 | 聊天历史、页面正文、完整导航路线 |
| QQ音乐、网易云、华为音乐、酷狗、喜马拉雅等 | 应用公开的 Android 媒体会话，需通知使用权 | 私有账号收藏、完整播放历史；未公开会话的应用不保证可读 |
| 铁路12306、携程、美团、京东等 | 本人选择后解析脱敏通知的行程、送达等提示 | 订单账号 API、完整订单历史；系统未投递的通知不可读 |
| 日历应用 | 已同步到系统 Calendar Provider 的计划 | 所有第三方云日历或真实出席 |
| 图库与相机 | 已授权的 MediaStore 内容 URI 和元数据 | 未授权的云端照片 |
| 兼容健康应用 | 已有 Health Connect 步数、运动与睡眠读取 | 此华为手机必定支持或已与华为账号互通 |
| 华为运动健康账号 | 当前仅提供状态与官方说明入口 | 历史步数、手表/手环数据已接入 |

这些是系统公开数据连接和可操作的应用选择，并非厂商 OAuth/订单 API 全部接入。常用应用分组只帮助查找；真正的能力取决于权限和应用是否提供相应系统数据。

## 运行效率与后台

- 自动补采串行且30秒内合并，手动刷新仍立即执行；失败/取消可重试。
- 修改通知或日历不会重启正在工作的计步器，避免不必要的重新建基线。
- 只有查看回忆、我的或趋势时才读取历史摘要；日期切换只读本地。
- 来源探测仅在状态变化时合并写入与刷新。位置分布单独查询位置行。
- 手机步数/位置都关闭时停止前台记录服务；只开步数时不注册定位用的显著运动触发器。

连续步数、位置需要后台；通知和播放需要系统监听；应用使用、图库、日历支持补采。无需亮屏；后台约30分钟的工作由系统安排，不能保证精确执行。目标华为手机的启动管理与电池设置见[华为接入准备](Huawei_Health_Integration.md)。没有实机性能对照，因此不提供启动加速或省电百分比。
