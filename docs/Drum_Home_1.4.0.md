# 1.4.0 · 转动这一天

2026-10-15。首页从纵向图文回顾改为一条可手动转动的横向经历时间线。此版本取代1.3.1“回顾在上、统计在下”的默认首页布局，保留原有数据与来源能力。

## 打开后看到什么

页面中央突出一段经历：时间、照片或活动图标、名称及实际时间区间。相邻经历沿圆弧后退，倾斜、缩小并淡出。左右拨动时，下一段逐渐转到正面，内容随之清晰浮现。一天按早到晚有界排列，不自动轮播，不把晚上循环成同一天的凌晨。

顶部只留日期、记录状态、刷新和统计入口；底部是同一时间线的定位刻度及原有导航。没有叠加统计面板或评分。图表从右上角进入独立“一天统计”页，仍可查看步数、影像、停留、小时手机使用与实际应用时段。

## 操作

| 操作 | 结果 |
|---|---|
| 左右拖动 | 连续转动；松手停在一段经历上 |
| 快速滑动 | 可跨过多段经历；单次最多吸附移动4页 |
| 点击左右箭头 | 上一段/下一段；到达当天边界时禁用对应方向 |
| 拖动一天时间刻度 | 跳到该时间附近真实存在的一段经历 |
| 点击凌晨/上午/下午/晚上 | 跳到该时段的首条；无记录时不可选择 |
| 点击中间卡片 | 查看原始片段、来源、修正与收藏等已有操作 |
| 点击两侧卡片 | 转到该卡片 |
| 点击右上角图表 | 打开一天统计，再从全部片段进入完整列表 |

没有记录时显示开启记录来源和虚构演示入口，不伪造一天的经历。演示有明确标识，不进入实际数据库。

## 数据与实现

- `DayMoments.kt`只创建展示投影，保留原始Episode供详情使用；按归档日界及截止时间裁剪，排除未来、计划、未知和时钟冲突。
- 普通片段按开始时间排列；步数区间出现一次，以报告末尾定位，保留原始数量，不按时段比例分摊。推测事件继续显示断言标签。
- `DayDrumUi.kt`使用Compose原生HorizontalPager和graphicsLayer。手势偏移映射到圆弧位移、Y轴转角、缩放和透明度；仅按需加载相邻页。动画不创建后台服务或定时任务。
- 列表使用实际片段ID作为稳定key；记录增减时，key与内容回调读取最新快照，避免页数更新先于旧闭包引发越界。离开详情返回时由现有SaveableStateHolder恢复位置。
- 照片沿用真实MediaStore缩略图加载及缓存。不可访问时显示提示，仍能进入片段详情；不使用素材照片替代用户生活记录。
- 大字体使用紧凑时间标题、较小图片区域和卡内纵向滚动；横屏将转筒与时间控制左右排布，保证经历与操作同时可见。
- 无新依赖、无数据库迁移、无新权限。继续复用原个人签名；1.0.2数据库PRAGMA修复与后续计步、授权、采集优化均保留。

实现参考：[Android Pager](https://developer.android.com/develop/ui/compose/layouts/pager)、[Compose图形变换](https://developer.android.com/develop/ui/compose/graphics/draw/modifiers)。

## 检查与升级

实际测试数量、签名和安装包校验见[验证报告](Verification.md)；原生渲染与设计复核见[设计检查](../design-qa.md)。渲染使用虚构记录，不是真机截图；目标华为手机的实际手势帧率、图库和系统后台行为仍需安装验收。

安装1.4.0个人Release可覆盖此前同签名版本，无需卸载。两个变体的首页和本地记录功能一致；离线版无INTERNET权限，增强版仍只有用户配置并主动触发的可选网络整理能力。
