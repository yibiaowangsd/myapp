## 发现与修订历史

1. 第一轮发现 P2：360dp / 1.5倍字体下长标题最后一字独占一行，日期中的星期被拆开；两列统计的影像标签和时长尾字零散换行，图表“60分”和所选小时用量也出现单字断行。证据为第一轮20/21渲染；临时保留在构建目录 `harmony-build/visual-home-iteration-1/`，不作为当前界面。
2. 修订：标题简化为“按时间回看”；日期和星期按完整文本放进 FlowRow；fontScale≥1.3时统计采用单列；图表单位单独标注，较大字体的所选时段和用量分两行。
3. 第二轮重新生成上述20/21渲染并与源图共同检查：标题、日期、统计和图表的操作均可见，先前P2已消除。首页先显示分时段卡片，统计与图表位于全部时段之后；没有剩余可操作的P0/P1/P2。

## 必查表面

| 表面 | 结果 |
|---|---|
| 字体和层级 | 沿用原生系统中文字体与Material排版；标题20sp/半粗，辅助文字14sp，时间标签更轻。大字体未强制缩小字号，采用换行和单列适配。与华为系统的具体字形存在平台差异，未冒称字体像素复刻。 |
| 间距和布局 | 沿用16dp页面边距、24dp卡片圆角；时间线左列36dp，列间10dp，卡片内16dp；照片两列、8dp间距。最后时段停止连线。先图文、后统计符合用户新要求。 |
| 配色 | 紫色主操作保持，时段增加暖棕/青绿/玫瑰辅助色，配合明确文字与图标，不靠颜色单独传意。深色使用现有亮色tokens。 |
| 图像 | 正式界面继续读取真实MediaStore缩略图；未更换图片加载、裁切实现，不引入虚构用户照片。测试URI不可访问时显示错误状态，两列与时间位置已验；真实照片锐度/URI访问属于设备复核项。 |
| 文案和内容 | 标题“按时间回看”；日期、时段、照片时间和统计均来自当前DayView。无记录用“—”，未到小时不可选。虚构测试数据和演示数据明确标注。 |
