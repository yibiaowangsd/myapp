# 1.4.0 转筒首页设计检查

final result: passed（原生组件范围；真实设备性能未测）

## 目标与证据

用户的新目标是首页只突出一条可左右手动转动的经历时间线，具有前后景深和浮现效果，并按早到晚回看。此前截图中的纵向分时段布局是上一版基线，不再作为本轮像素复刻目标。统计通过独立入口保留。上一版检查归档在[1.3.1](../v1.3.1/design-qa.md)。

本项目为既有Android原生Compose应用；没有浏览器表面，因此不报告浏览器QA。测试使用生产组件、Robolectric API35 native graphics以及Android View.draw/Skia。虚构测试记录没有写入真实数据库，未把用户截图、照片或生活记录加入仓库。

## 迭代发现

1. 第一轮P2：大字体下照片区域过高，标题后的内容被挤出卡片首屏；中间态的透视方向更像向内翻页，卡片过高削弱了浮现感。原始本地证据为`harmony-build/drum-iteration-1/26-drum-large-dark.png`与`28-drum-depth.png`。
2. 修订：大字体将时段和时间合并为一行，减少图片高度并保留卡内滚动；正常尺寸约束卡片高度，调整转角方向与圆弧半径。最终22、23、26、28经原尺寸目视检查，中心内容清晰、邻近经历随手势退后和浮现。
3. 刷新交互测试发现页数更新和旧key闭包不同步导致越界，已修正为最新快照读取；最终用例验证插入后仍停留原经历、删除当前经历后安全显示下一段。
4. 横屏采用左右布局，经历标题和时间定位同时可达。保留一个低优先级视觉细节：非常小的横屏缩略图里，照片不可访问提示可能折行裁切；片段标题和详情入口保持可用。不影响主交互。
