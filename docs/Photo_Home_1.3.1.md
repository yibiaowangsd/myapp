# 1.3.1 · 图文首页与日统计

此次调整以用户提供的“一天总结”截图为结构依据。打开 App 的默认页面就是分时段图文回顾，统计和图表统一下移。

## 页面顺序

1. 日期、记录状态和刷新。
2. “按时间回看”与“全部片段”入口。
3. 凌晨 / 上午 / 下午 / 晚上的卡片，只呈现已有记录的时段；照片、文字、媒体和应用图标。
4. 一天统计：步数、停留段数、影像数、手机使用。
5. 手机使用节奏：按小时柱图，点选柱子或前后按钮查看时段用量。
6. 应用使用区间：图标、开始/结束、时长和时间色条，保留间隔。
7. 计步提示、权限和记录开关。

## 视觉与交互

沿用浅灰底、白色圆角卡片与紫色操作；时段用统一的语义图标和柔和辅助色。两列缩略图优先于次要文字，图片下标明时间。默认展示前两项，多于两项有明确展开/收起入口。卡片应用图标横向滚动，照片、应用和事件都可打开原片段。

完整片段页继续支持日期、分类、位置分布和修正入口；从详情返回保留首页状态。深色模式和大字体使用相同数据与操作。

## 数据口径

小时用量与总量均来自观察区间并集，裁剪到当天和观察截止时刻。分屏重叠不重复计算手机总量；按实际归档日支持 23/25 小时。计划、未知和时钟冲突不进入既成经历。无权限/无数据为“—”，不画虚构柱子；未到的小时不可点选。

照片仍由本机 ContentResolver 读取真实 URI，不上传、不复制原图，无法读取时保留明确提示。本次参考截图及其中的个人照片不加入仓库。测试渲染使用虚构事件和不可访问的测试 URI，真实图库内容与华为界面需要在手机上验收。

## 安装与验证

两个 Release 使用原包名及个人签名，版本 1.3.1（7），可覆盖安装；通常选择 Offline。Enhanced 仅额外保留手动网络增强能力，首页完全相同。
