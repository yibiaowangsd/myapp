# 华为运动健康接入准备

核对日期：2026-10-15。目标设备：HUAWEI HBN-AL80，HarmonyOS 4.2 / Android 12 API 31。当前工程是 Android APK，采用 Android 接入路径。

## 当前状态

1.3.0 **尚未接入华为账号健康数据**。工程没有有效的华为应用 App ID、服务开通结果、获批的数据权限配置和真实授权令牌，也没有集成 HMS Health SDK。连接页如实显示此状态；“打开运动健康”只启动已安装应用，并非授权成功。

手机硬件步数通过 Android SensorManager 独立读取；Health Connect 是另一种系统数据平台。不能将身体活动权限、华为运动健康已安装，或 Health Connect 已授权解释为华为账号数据可读。

## 官方流程与所需材料

| 阶段 | 需要完成的事项 | 本项目准备情况 |
|---|---|---|
| 应用登记 | 在华为开发者平台创建应用，开通账号服务，取得应用配置 | 缺本人平台应用配置 |
| 数据资格 | 申请 Health Service Kit 与所需读取权限，通过运动健康数据审核 | 缺服务/数据权限审核结果 |
| 标识与签名 | 登记真实包名与发布签名指纹，按所选 SDK 配置 App ID/项目配置 | 包名和签名已确定，见下表 |
| SDK 集成 | 使用官方 Android SDK、授权回调和数据读取接口 | 待配置和获批能力确定后实施；不得填虚构 App ID |
| 用户授权 | 在应用内启动华为账号登录与数据授权，同意获批的数据范围 | 目前没有可调用的真实授权流程 |
| 数据同步 | 按所选接口读取获准的步数、运动、睡眠，处理撤权和无数据 | 待真机联调；不能假设每个账号都可读取所有数据类型 |

官方 FAQ 明确指出：端侧用户授权之前需要运动健康数据审核通过，否则用户同意也不产生第三方数据访问资格。官方 Android 示例要求应用标识、签名配置和 SDK；不能只补一个系统权限弹窗。

| 登记字段 | 本项目值 |
|---|---|
| 应用名称 | 我 |
| Android 包名 | `com.personal.wo` |
| 发布证书 SHA-256 | `c9b24de261dc30ebbc92da22f3f7826beb2c3015141c7b43d63b1ca27de9cb58` |
| 请求方向 | 优先只读步数、运动和睡眠；实际能力以平台审批为准 |

可以提供 App ID、对应应用配置以及获批的数据范围来完成后续集成；不要发送开发者账号密码或签名私钥。涉及 client secret 的云侧实现需保留在服务端，不能硬编码在 APK。当前离线包无 INTERNET，若最终选择依赖网络的授权/数据路径，应放在增强变体并明确提示。

## 用户端操作

完成正式接入后，在“我”里发起真实华为授权；也可在华为运动健康的“我的 → 隐私管理 → 数据分享与授权”检查、调整或撤销。入口名称受运动健康版本影响。还需按所选接口要求开启运动健康服务、手表/手环同步或云同步；本应用尚未出现在授权列表属于当前未接入状态。

验收必须覆盖拒绝、取消、部分授权、撤权、账号切换、网络中断、当天/跨日统计、时区、数据来源与手机计步重复去重。华为总步数不能直接与手机增量步数相加。

## 后台常驻与目标手机

当前应用无需亮屏。连续手机计步和位置采集需要后台前台服务；通知/媒体依赖系统监听，进程或监听中断后的内容通常无法补回。应用使用、图库、日历可在打开时或约30分钟的系统调度任务补采，系统历史保留和权限会限制补采范围。

华为针对 HarmonyOS 4.2 等系统的官方第三方计步故障说明指出，后台清理可能造成步数偏少或轨迹异常，并给出应用启动管理、电池优化和最近任务锁定设置。用户可在设置搜索“应用启动管理”，将“我”设为手动管理，允许自启动、关联启动和后台活动；仍有中断再按官方步骤排查电池优化。应用不能自行绕过这些设置，也无法保证强制停止后持续记录。

如果只要打开时的应用时段、照片和日程，可在来源管理关闭位置和手机计步；两项关闭后本应用停止前台记录服务。通知访问权限如果仍开启，系统绑定的通知监听可能继续存在。完整停止记录使用“我的 → 暂停”，彻底撤销监听可在系统关闭通知使用权。
