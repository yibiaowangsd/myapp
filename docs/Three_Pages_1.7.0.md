# 我 · 1.7.0 三页增强版

构建基线：`bd49e4990ccc0e19ba2fec1384eb666f69e3037c`，包含最新时间轴动效与个人成就系统。

## 页面

底栏只保留三个主页面，首次打开进入首页。

| 页面 | 内容 |
| --- | --- |
| 首页 | 横向时间轴、上下错落的大事件卡片、双侧连续景深、随时间变化的背景、照片与事件详情。点击顶部日期回看历史，保留统计与全部片段入口。 |
| 成就 | 32枚原创徽章、8个系列、4个阶段，自定义目标、阅读应用选择、解锁条件、进度、获得日期及个人展台。 |
| 设置 | 记录启停、权限、应用与来源、计步与后台运行、生活趋势、隐私锁、数据导出与恢复、可选增强配置。 |

事件详情、成就详情、权限管理等属于所属主页面的二级操作，不新增底栏。设置内从“应用与来源”进入权限后，返回原入口；从成就或设置按系统返回键回到首页。

成就整理只在成就页可见时进行，应用列表在进入连接管理或选择阅读应用时加载，生活趋势在查看时加载。成就演示不写入真实成就。

- 文件：`Wo_Android_v1.7.0_Enhanced.apk`。
