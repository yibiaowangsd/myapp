## 安装与首次配置

1. 将本次交付的`Wo_Android_v1.7.0_Enhanced.apk`传到手机并安装。要求Android10及以上，64位ARM运行环境。安装包沿用原个人签名；不需要安装Android Studio。本次仅交付增强版，离线变体源码仍保留。
2. 首次配置会直接申请系统权限，没有欢迎页、勾选页或用途二次确认。身体活动、照片、定位等普通权限合并为一次请求，由系统显示各权限组；随后依次进入需要的使用情况访问、通知使用权设置。
3. 返回应用后自动刷新授权结果，首次使用自动开始记录；拒绝和不支持的来源不会阻止进入首页。已授权内容不会反复请求，用户暂停/停止的记录不会因升级被重新开启。
4. “设置 → 记录权限”可以直接管理单项系统权限，也可点击“申请未开启的权限”。后台定位、后台运行、可选健康和无障碍仍有独立系统入口。
5. 步数默认使用本机硬件计步，不要求连接Health Connect或华为运动健康。检查累计计步器、唤醒传感器和单步检测器；连接失败会显示原因并提供重连。不能读取启用前的历史步数，不把开机累计值当作今日步数。
6. 打开直接进入“首页”：左右拨动转筒，按真实时间回看停留、运动、影像和长时间应用等大事件；两侧使用一致的景深，背景随正在浏览的时间连续变化。照片在卡片中直接显示；应用默认单次至少10分钟才突出，可在右上角“⋮”改为5/10/20/30分钟。轻触卡片查看关联片段与影像；首页“全部片段”可查看收起的小记录，短使用不会删除。点击顶部日期打开日历，也可前后翻日、回到今天；图表按钮进入所选日期的一天统计。
7. 无记录或权限缺失显示“—”；虚构示例始终标明演示。照片打不开时显示不可访问，不用虚构图片代替。在“设置 → 应用与来源 → 应用连接”按真实应用图标选择通知线索，不再填写包名；“来源与后台”管理音乐、日历、图库、健康和后台运行。

侧载应用的某些特殊访问入口可能要求在系统应用详情中确认“允许受限设置”；仅使用系统提供的入口。应用不自动点击或绕过授权。系统后台策略因设备不同需要实际验证。

## 操作

- 时间轴：一个大事件一张卡片，按实际时间排列，左右都有景深，背景随浏览时间变化。长应用按实际区间计时；短使用收进详情或全天“全部片段”。照片嵌在轴内；日期边界卡片可进入前后日期，今天末尾显示记录截止时间。返回详情保留日期和位置。
- 一天统计：右上角图表进入，包含一天统计、可点选的小时柱图和真实应用时段；“全部片段”进入日期切换与分类筛选。
- 成就：32枚原创徽章、8个系列、4个阶段，支持阅读应用选择、自定义目标、详情和个人展台。演示成就不会写入真实记录。
- 设置：集中管理记录状态、权限、应用与来源、后台运行、生活趋势、隐私、备份恢复和增强配置。应用连接按图标选择，不需要手输包名。华为账号健康数据尚未接入。
- 历史日期：从首页顶部日期打开日历，或使用前后一天切换；不再占用单独的底栏。
- 日详情：完整片段列表；有位置证据时可以展开离线位置分布。位置分布没有街道底图，不补造缺失路线。
- 片段：来源依据、标题与时间修正、本人确认、收藏、地点命名和删除。
- 暂停/停止、排除、删除防重导、加密备份与恢复继续使用已有实现。
- 生活趋势：最近七天应用活动柱图；达到样本和覆盖要求后展示已有规律。暂无记录用“—”表示。

日历保留为计划，通知是线索，应用活动可重叠。手机活动总量取区间并集。手机未交互不会被识别为睡眠；没有可靠终止边界的应用或媒体片段不计算成全天时长。图片缺少可靠拍摄时间时显示为添加图片。

## 加密备份与迁移

当前完整备份对每类JSONL明细设有50000条上限；达到上限时会拒绝导出，需要进一步增加范围完整备份入口。此限制已列为首版边界。

完整备份后会显示一个单独的恢复码，务必自行保存。恢复码不写入备份文件。格式为`WOARCH01`外层头、包装后的独立keyset及AES256_GCM_HKDF_1MB流式认证加密载荷。载荷是固定七项ZIP，含逻辑观察、片段、修正、地点、策略和每日视图，不包含照片原图、旧设备授权或API访问密钥。

恢复先完整认证流、校验条目、限额和哈希，再导入独立加密暂存数据库并检查完整性；最后在正式数据库的单个事务中替换数据，失败回滚。成功后保持停止状态，重新检查授权并开始记录。跨设备恢复不会直接访问旧照片URI，媒体需要重新索引或关联。

日Markdown/JSON导出是本人主动生成的可读副本，默认移除通知正文、精确坐标和图片URI。

## 变体

`personalOffline`是默认成品方向，完整本地日视图不依赖网络。`personalEnhanced`拥有INTERNET权限，仅在设置HTTPS事实整理端点并主动点击按钮后发送已有事实；返回值只能是合法事实ID顺序。最终文案仍由本地生成，每日最多三次，访问密钥使用Keystore加密保护。两个包使用相同applicationId和个人签名，可以覆盖安装。

增强端点直接接收以下JSON，不自动假定某个模型厂商的聊天接口格式。需要按此协议配置端点或添加服务端适配：

```json
{"task":"arrangeFacts","model":"optional-model","facts":[{"id":"steps","type":"STEPS","value":"4280步"}],"outputContract":"..."}
```

允许返回：`{"factIds":["steps"]}`。未知ID、重复ID、额外字段、超过四项等结果被拒绝，保留本地摘要。没有发送照片、通知原文或精确坐标。网络增强目前由本人主动触发，没有后台定时模型任务。

## 开发与构建

安装JDK17、Android SDK Platform36、Build Tools36.0.0和Android Studio。Gradle Wrapper已附带，分发包与依赖提供SHA-256校验记录和依赖锁。首次构建需要解析固定依赖；本源码包不包含SDK及完整Maven缓存。

```bash
./gradlew :core:test :app:testPersonalOfflineDebugUnitTest :app:lintPersonalOfflineDebug :app:lintPersonalEnhancedDebug
./gradlew :app:assemblePersonalOfflineDebug :app:assemblePersonalEnhancedDebug
./gradlew :app:assemblePersonalOfflineDebugAndroidTest
./gradlew :app:connectedPersonalOfflineDebugAndroidTest
```

Windows使用`gradlew.bat`。发布签名通过环境变量配置，私钥不在源码中：`WO_KEYSTORE_PATH`、`WO_KEYSTORE_PASSWORD`、`WO_KEY_ALIAS`和`WO_KEY_PASSWORD`。使用单独交付的签名备份进行后续覆盖升级。

```bash
./gradlew :app:assemblePersonalOfflineRelease :app:assemblePersonalEnhancedRelease
```

Release仅打包arm64-v8a，启用R8与资源压缩，关闭debuggable。Debug另含x86_64供模拟器测试，使用调试签名，不能与个人签名的Release直接覆盖。

## 工程

- `core/`：纯Kotlin模型、半开区间、排除、应用会话、停留、媒体、通知脱敏、摘要、规律和领域/加密测试。
- `app/.../collector/`：框架定位、计步、UsageEvents、通知/媒体、窗口元数据、MediaStore、日历、Health Connect及恢复调度。
- `app/.../data/`：17张Room表、单写入互斥通道、加密密钥保护、搜索、修正/删除及备份。
- `app/.../ui/`：直接授权、首页时间轴、成就、设置、详情、搜索及可视化。
- `app/schemas/`：实际生成的Room V1 schema；`contracts/schema.sql`由该schema导出。
- `app/src/androidTest/`：SQLCipher加密、去重、暂停代次、删除防重导和备份往返/认证失败设备测试。

已交付版本均沿用数据库V1，本次覆盖升级无需迁移。后续变更数据库结构必须增加显式Migration，不使用破坏性迁移。物理数据库损坏、密钥不可用时保留文件并停止正常写入；当前初始化失败状态下的独立救援恢复入口尚需继续完善，不能自动清库。

## 与设计基线的实现差异及待验收

低功耗框架定位确认停留时使用0米最小位移，候选阶段最多12分钟、约3分钟请求，停留阶段约15分钟请求。若坚持50/250米位移过滤，静止设备可能不产生足够位置确认停留；这项调整没有延长GNSS硬预算，仍需真机耗电对照测试。

首版将多数功能放在单app模块内，仅领域引擎独立为JVM模块。恢复最后使用SQLite单事务替换，而不是直接替换已打开的数据库文件，保留失败回滚语义。CPU与内存目标、后台冻结、来源准确率、OEM系统、200%字体、16KB设备及7日稳定性尚需设备验收。已实现800MB软预算降级、原始观察30天、通知正文7天、诊断7天、730天非收藏片段清理。自动媒体撤回对账、Health Connect变更令牌优化、大规模恢复/迁移、更完整的媒体重新关联与规律样本评估还需补齐或验证。健康来源当前以有界7日快照对账，因此更早记录的撤回不在此路径的实时对账范围内。

完整功能闭环已落入工程，但本交付不冒充已通过全部G01—G08发布验收的正式生产版本。
