# 我 · 生活回顾

**让今天成为回忆。** 原生 Android 应用，把授权照片与生活片段整理成可以转动、搜索、修正和分享的时间轴。

源码版本 **2.2.1** · Android 10 及以上 · Kotlin / Jetpack Compose · 本地优先，无需注册。

## 这一版

- **DeepSeek 与长期记忆**：在右上角设置中填写自己的 DeepSeek API Key，结合近期记录、已存偏好和历史观察生成回顾；支持可选每日自动回顾。记忆加密持久保存，可备份和清空，并通过原数据互通共享给 ChatGPT；不增加聊天页面。参见[接入与记忆说明](docs/DeepSeek_Memory.md)。

- **仅一个增强版**：移除离线构建配置，沿用原应用标识；成就页直接展示勋章，管理和筛选收进选项。
- **ChatGPT 数据互通**：在右上角设置中连接自己的私有 GitHub 数据仓库，持续同步结构化日记录。ChatGPT 通过现有 GitHub 连接读取这些历史来源，继续在原来的聊天中分析。App 不增加聊天窗口、不需要 OpenAI API 密钥。参见[连接说明](docs/ChatGPT_Data_Link.md)。

- **生活胶片首页**：大日期、全幅照片、上下错落事件卡、连续双向景深与随回看时间变化的光线；保留真正的水平时间轴。底部仅首页和成就两个入口，设置位于右上角。
- **从照片开始**：首次进入由用户选择相册授权，支持 Android 14 的部分照片访问；可以跳过。其他来源在需要时单独连接。
- **找回历史**：首页直接搜索，最近回忆、照片、收藏、地点和应用筛选；支持日期和关键词组合查询。
- **历史照片导入**：最近30天、一年、全部；按批整理，显示进度并可停止，完成的记录立即可检索。
- **修正与收藏**：编辑片段标题和时间、命名地点、收藏与删除。照片画廊保留全部关联媒体，支持打开原图。
- **分享这一天**：在首页菜单生成原创回忆卡，经过系统分享面板自行选择接收应用。
- **成就馆**：沿用32枚徽章、自定义目标和个人展台，依据已保存的记录计算。
- **本机保管**：加密数据库、可选系统身份验证、加密备份和恢复。保留原应用包名、签名和数据库结构用于覆盖升级。

## 安装和使用

正式安装使用带原发布签名的 `Wo_Android_v2.2.0.apk`。旧版覆盖安装可保留记录与已有暂停状态。2.2.1 修复私有数据与记忆同步，须使用原发布签名构建后覆盖升级。CI 的未签名 Release 不能用于覆盖升级。参见[修复与验收说明](docs/Shared_Data_Sync_Recovery.md)。

1. 新用户点“从照片开始”，选择允许的照片；应用整理最近30天的影像。也可以先进入界面看看。
2. 左右转动首页生活胶片，点击事件查看完整片段和照片。点日期可回到任意过去日期。
3. 首页放大镜进入“搜索回忆”；支持 `昨天`、`2026-10`、`2026-10-21` 等日期查询，以及片段名称、地点或应用关键词。照片内容本身没有做图像语义识别。
4. 搜索页的照片导入入口可选更长范围。照片原图仍由系统相册管理；移除文件或撤回访问后，原图可能无法查看。
5. 在“设置”按需连接运动、日历、位置、应用等来源；首次使用不会自动跳转使用情况或通知访问设置。
6. 首页菜单“分享这一天”生成图片并打开系统分享面板。应用不会自动发送。

过去的系统行为无法全部补回。相册中的拍摄时间优先作为记录时间；没有拍摄时间的文件按添加时间展示。日历是计划，推测停留明确标注；应用不会凭空补全一天。

## 数据与升级

- 应用标识 `com.personal.wo`，版本号16，沿用V1数据库；升级不清库。
- 照片片段和收藏长期保留；原始观察默认保留30天，通知正文7天，其他非收藏片段730天。照片原图不会复制进数据库。
- 暂停、停止、排除和删除防重导仍生效。历史导入不会重新开启用户已经暂停的记录。
- 加密备份包含长期记忆，不包含照片原图、系统权限、同步令牌或 DeepSeek API Key。请单独保管恢复码；跨设备恢复需要重新连接来源。
- 本项目统一为增强版，数据互通需要自行开启。华为官方健康账号读取仍需要真实应用登记及获批权限，基础照片回顾和手机计步不依赖它。

## 构建

JDK17、Android SDK36、Build Tools36.0.0。固定依赖锁与校验记录保留。

```bash
./gradlew --no-parallel --max-workers=1 :core:test :app:testPersonalEnhancedDebugUnitTest
./gradlew :app:lintPersonalEnhancedDebug
./gradlew :app:assemblePersonalEnhancedRelease
```

发布签名由环境变量 `WO_KEYSTORE_PATH`、`WO_KEYSTORE_PASSWORD`、`WO_KEY_ALIAS`、`WO_KEY_PASSWORD` 提供；私钥不进入仓库。无签名配置的Release产物是未签名包，不能作为覆盖升级安装包。
